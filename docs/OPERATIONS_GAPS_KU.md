# پاراستنی داتا و یەکخستنی ناسنامە

## پاشەکەوتی دەرەکی

`.github/workflows/external-db-backup.yml` ڕۆژانە PostgreSQL custom dump درووست دەکات،
پێش هەناردەکردن بە AES-256-GCM دەیپارێزێت، دڵنیادەبێت فایلەکە دەکرێت
بکرێتەوە، و تەنها فایلە پارێزراوەکە بۆ GitHub Actions Artifact دەنێرێت
(ماوەی پاراستن: ٣٠ ڕۆژ). ئەمە سەربەخۆیە لە پاشەکەوتی ناوخۆی Supabase.

بۆ چالاکبوونی خۆکاری: workflow دەبێت لە **default branch**ی GitHub هەبێت،
و ئەم دوو Repository Secretـە پێویستن:

- `ZHIROX_BACKUP_DB_URL`: پەیوەندیی ڕاستەوخۆی PostgreSQL بە مۆڵەتی پێویست بۆ `pg_dump`؛ تەنها لە GitHub Secrets دابنرێت.
- `ZHIROX_BACKUP_KEY_B64`: ٣٢ بایتی هەڕەمەکی بە Base64، بۆ نموونە بە `python3 -c 'import os,base64;print(base64.b64encode(os.urandom(32)).decode())'` درووست دەکرێت. کلیلی ئەسڵی لە شوێنی پارێزراو دەرەوەی GitHub بپارێزرێت؛ ونبوونی کلیل واتە ناتوانرێت پاشەکەوتەکان بکرێنەوە.

بۆ تاقیکردنەوەی گەڕاندنەوە، فایلەکە لە Artifact دابەزێنە و لە ئامێری
پارێزراو `python3 scripts/verify_external_backup.py archive.zhxb database.dump`
جێبەجێ بکە؛ پاشان `pg_restore --list database.dump` و تاقیکردنەوەی restore
تەنها لە پڕۆژەی تاقیکردنەوە ئەنجام بدە. پشتڕاستکردنەوەی کۆدکراو
تاقیکردنەوەی restoreـی ڕاستەقینە لە پڕۆژەی جیاواز نییە.

## ناسنامەی کڕیاری دووبارە

یەکخستنەکە **ناسنامەکان بە یەکەوە دەبەستێت** و کۆی ماوەی دیناری گرووپ
پیشان دەدات. قەرز، پارەدانەوە، چاتی دارایی و پەیوەندی Daftar لە ناسنامەی
ئەسڵی خۆیان دەمێننەوە. ناوی هەر کڕیارێک لە گرووپەکە بکەوە بۆ بینینی
مێژووی تایبەتی؛ یەکخستنەکە دەتوانرێت جیابکرێتەوە. تەنها بەڕێوەبەری
هەمان مارکێت دەتوانێت دوو ناسنامەی هەمان ناو یان هەمان ژمارە بە یەکەوە ببەستێت.
